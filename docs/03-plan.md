# 03. 구현 계획 — meet-room

## 기술 구조

| 항목 | 선택 |
|---|---|
| 프레임워크 | Next.js 15 (App Router) + TypeScript |
| 스타일 | Tailwind CSS |
| 데이터 / 로그인 | Supabase (Postgres + 내장 회원 기능) |
| 배포 | Vercel (마지막에, 원하실 경우) |

```
meet-room/
├─ docs/              기획 문서 3개
├─ src/
│  ├─ app/            화면 (로그인 / 회원가입 / 메인 표)
│  ├─ components/     표·예약 블록·입력 패널 등 화면 조각
│  └─ lib/            Supabase 연결, 시간 계산 함수
└─ supabase/          DB 테이블 정의 + 회의실 8개 초기 데이터
```

## 데이터 구조 (표 3개)

- **profiles** — 회원. 로그인 계정과 1:1. `표시이름`, `팀`
- **rooms** — 회의실 8개. `이름`, `표시 순서`
- **reservations** — 예약. `회의실`, `시작시각`, `종료시각`, `목적`, `만든 사람`

핵심 규칙 두 가지를 DB에 직접 걸어둔다 (화면 코드가 실수해도 데이터가 깨지지 않게):
1. **같은 방 · 겹치는 시간**의 예약은 애초에 저장되지 않는다.
2. **예약을 지우거나 고치는 건 만든 사람만** 가능하다.

## 각 마일스톤 상세

### M1 — 프로젝트 뼈대 + DB 준비
**할 일:** Next.js 프로젝트 생성 / Tailwind 설정 / Supabase 프로젝트 연결 / 표 3개 만들기 / 회의실 8개 넣기 / 위 "핵심 규칙 두 가지" 걸기
**검증:** 자동 — 빌드 통과. 수동 — 브라우저에 첫 화면이 뜨고, Supabase 화면에서 회의실 8개가 보인다
**막힐 수 있는 지점:** Supabase 계정·프로젝트가 필요합니다. 없으면 M1 시작할 때 만드는 걸 안내드립니다

### M2 — 회원가입 · 로그인
**할 일:** 회원가입 화면(아이디·비밀번호·이름·팀) / 로그인 화면 / 로그아웃 / 미로그인 시 메인 접근 차단 / 상단 바에 내 이름 표시
**검증:** 자동 — 빌드·타입 통과. 수동 — 가입→로그인→메인 진입, 로그아웃 후 메인 주소 직접 입력 시 로그인 화면으로 튕김

### M3 — 표 그리기
**할 일:** 상단 바 48px / 8열 × 20행 격자 / 왼쪽 시간 열과 위 회의실 행 고정 / 한 칸 32px
**검증:** 수동 — 스크롤해도 시간·방 이름이 안 사라진다. 데스크톱에서 하루가 한 화면에 들어온다

### M4 — 예약 표시
**할 일:** 오늘 예약 불러오기 / 시간 길이만큼 블록 높이 계산 / 목적 + 예약자 이름 표시 / 내 것과 남의 것 색 구분
**검증:** 수동 — DB에 직접 예약 몇 개를 넣고 새로고침하면 정확한 칸에 얹힌다

### M5 — 클릭·드래그로 예약
**할 일:** 칸 클릭 시 30분 선택 / 세로 드래그로 구간 선택 / 남의 예약 만나면 멈춤 / 방을 넘는 드래그 차단 / 입력 패널 / 저장 / 겹침 거절 시 안내 메시지
**검증:** 자동 — 시간 겹침 판정 함수 테스트. 수동 — **S1 시나리오 전체 재현**, 이미 찬 시간에 억지로 예약 시 안내 메시지

### M6 — 취소
**할 일:** 내 예약 클릭 시 상세 + 취소 / 남의 예약은 정보만 / 취소 후 표 즉시 갱신
**검증:** 수동 — 다른 계정으로 로그인해 남의 예약에 취소 버튼이 없는지 확인

### M7 — 날짜 이동 + 현재 시각 (차별점 구현 지점)
**할 일:** 날짜 앞뒤 이동 + "오늘" 버튼 / **빨간 현재 시각선** / **지난 칸 흐리게 + 클릭 차단** / **첫 진입 시 현재 시각으로 자동 스크롤** / **지금 칸 클릭 시 시작 시각을 현재로 채움**
**완료 조건:** 화면을 열었을 때 "지금 이후 비어 있는 칸"이 따로 찾지 않아도 눈에 먼저 들어온다
**검증:** 수동 — 시각을 바꿔가며 선 위치 확인, 어제 날짜는 전체가 흐리게

### M8 — 모바일 + 최종 점검
**할 일:** 열 최소 폭 88px + 가로 스크롤 / 터치 드래그 / README / 환경변수 예시 파일 / .gitignore
**검증:** 자동 — 빌드·타입·테스트 전부. 수동 — **S2 시나리오를 휴대폰 크기에서 재현**, 한글 입력, 빈 목적, 아주 긴 목적
